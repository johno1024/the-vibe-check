# The Vibe Check 👀

A mobile-friendly compatibility/love-language game for two people.

## How it works
- Person 1 takes the test first.
- The site generates a private partner code containing Person 1's locked answers.
- Person 2 opens the same site, chooses "I have a partner code," pastes it, and takes the test without seeing Person 1's answers.
- Results are revealed only after Person 2 finishes.
- If either person chooses the explicitly platonic answer on the final mutual-attraction question, the other person's exact romantic answer is not revealed.

## Hosting
This project is intentionally a single `index.html` file so it can be hosted for free on GitHub Pages with no database or build system.

## Privacy note
The partner code is encoded, not encrypted. It is designed for a fun social game, not sensitive or confidential information.
